# India Tourism Dataset: Data Dictionary

**Every row in every table is synthetic or unverified.** No real government figures are used.
Each table has `data_source` (text) and `is_synthetic` (boolean, `true` on every row), so a dashboard can
filter or flag by it. Regenerate with `python src/build.py`; check with `python validate.py`.
Generator is seeded (`seed=42`) and byte-reproducible.

**Status labels**
- **SYN**: generated by `src/synthesize.py` from illustrative anchors.
- **REF**: hand-entered reference value (`src/reference.py`), approximate and unverified (e.g. area, Census-2011 population, whether a site is UNESCO/ASI-listed). Flagged `is_synthetic=true` because it has not been checked against an official source.

**Conventions:** counts are integers; money is in ₹ crore (except `avg_spend_per_tourist`, in ₹); percentages are 0–100; `year` is the calendar year, 2015–2025.

**Boundary handling**
- J&K and Ladakh are separate from 2019. Before 2019, `JK` rows are the undivided state (including Ladakh) and there are no `LA` rows. See `state_boundary_mapping`; `tourism_annual.boundary_basis` marks the basis, and `yoy_*` is null where the basis changes.
- Dadra and Nagar Haveli and Daman and Diu use the merged entity (`DD`) for all years.
- Telangana (`TS`) exists for all years. Name variants (Orissa, Pondicherry, …) are resolved via `state_name_aliases`.

**Anchors:** national yearly totals in `national_annual` are hard-coded *illustrative* values (pre-COVID growth, 2020–21 collapse, recovery). State figures are apportioned so that state sums equal national totals exactly.

## states.csv (REF), 36 rows
| Column | Unit | Description |
|---|---|---|
| state_code | text | 2-letter key (PK) |
| state_name | text | Standardised current name |
| region | text | North / South / East / West / Central / North-East / Islands |
| capital | text | Capital |
| area_km2 | km² | Approximate area |
| population | persons | Census 2011, approximate |
| tourism_type_tags | text | `;`-separated: heritage, beach, hill, religious, wildlife, adventure, medical |
| data_source, is_synthetic | | |

## tourism_annual.csv (SYN), state × year (PK state_code, year)
| Column | Unit | Description |
|---|---|---|
| domestic_visits, foreign_visits | count | Visits in the year |
| yoy_growth_domestic, yoy_growth_foreign | % | Year-on-year change; null for 2015 and across a boundary change |
| share_of_india_total | % | (domestic+foreign) / national (domestic+foreign); sums to 100 per year |
| tourism_revenue_cr | ₹ crore | domestic×domestic spend + foreign×foreign spend |
| forex_earnings_cr | ₹ crore | Foreign-visit spend only (≤ revenue) |
| gsdp_cr | ₹ crore | Synthetic nominal GSDP, used for the share below |
| tourism_share_of_gsdp | % | revenue / gsdp × 100 |
| avg_spend_per_tourist | ₹ | revenue × 10⁷ / (domestic+foreign visits), blended |
| tourism_employment | persons | Synthetic, scales with revenue^0.9 |
| boundary_basis | text | `current boundaries` or `undivided J&K incl. Ladakh (pre-2019)` |

## tourism_monthly.csv (SYN), state × year × month
`domestic_visits`, `foreign_visits` (count; monthly sums equal annual exactly), `avg_temp_c` (°C, synthetic climate curve with slight warming trend), `season` (Winter Dec–Feb, Summer Mar–May, Monsoon Jun–Sep, Post-monsoon Oct–Nov).
Seasonality: hill states peak in summer, beach states in winter, desert and plains in Oct–Mar, a monsoon dip for most, and a COVID lockdown profile in 2020–21.

## infrastructure.csv (SYN), state × year
| Column | Description |
|---|---|
| hotels_total | Count; equals the sum of the six class columns |
| hotels_1star … hotels_5star, hotels_heritage | Hotels by class |
| hotel_rooms | Rooms (class-weighted) |
| occupancy_rate | % (0–100), tied to visits relative to 2019 |
| airports, international_airports | Counts (international ≤ airports) |
| registered_homestays, registered_tour_operators | Counts |

## attractions.csv (SYN footfall, REF flags), one row per attraction
`name`, `state_code`, `type` (heritage, religious, hill, beach, wildlife, nature, adventure, museum, entertainment, art), `is_unesco`, `is_asi_protected` (REF, unverified), `annual_footfall` (visitors, SYN, drawn from a popularity tier), `footfall_year` (2024).

## ftv_source_countries.csv (SYN), state × year × country
`foreign_visits` by country (United States, Bangladesh, United Kingdom, Canada, Australia, Germany, France, Sri Lanka, Malaysia, Japan, Russia, Others). Sums to the state's annual `foreign_visits` exactly. Regional tilts are applied (e.g. Bangladesh in WB/TR/ML, Russia in Goa).

## festivals_events.csv (REF), `name`, `state_code`, `month` (1–12), `type`
Festival names and months are hand-entered and unverified.

## Supporting tables
- **national_annual.csv** (SYN): `year`, `domestic_visits_total`, `foreign_visits_total`, `tourism_revenue_cr_total`, `forex_earnings_cr_total`.
- **state_boundary_mapping.csv** (REF): legacy entity → current state code, effective year, `indicative_share` (an assumption), note.
- **state_name_aliases.csv** (REF): `raw_name` → `standard_name`.
